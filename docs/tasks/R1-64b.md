It verifies the producer/factory/source bindings and the ordinary driver's recipe/payload/code guards.

Inspection, no model:
```bash
PYTHONDONTWRITEBYTECODE=1 JAX_PLATFORMS=cpu CUDA_VISIBLE_DEVICES= ../venv/bin/python -m scripts.r1_64b_comparator_recipes run --manifest docs/tasks/R1-64b-zsre-S1_literal.recipe.json --manifest-sha256 <hash-from-inventory>
```

Owner execution: use the same command with --execute on the owner GPU environment, under the existing shared GPU lease and resource supervision; --resume is allowed only with --execute. The CPU environment prefix above is for inspection, not the GPU run. This entry point itself does not acquire a lease or enforce a total profile budget; it retains the existing owner-managed development execution contract. No confirmation admission is granted.

To generate another recipe, use the build subcommand with --source, --source-sha256, --condition and a new --output under docs/tasks. The builder reads/verifies the source population, recomputes condition identity and writes a new immutable recipe. It never hand-edits or repurposes a previous recipe.
