The producer requires exactly seven completed steps in the hash-chained operator journal. It reconstructs each exact request using the installed producer/implementation bindings, previous input document, signed fields, stage request, endpoint request and written endpoint identities. It checks the named/date signature, matching unblocked preview, every state transition and current candidate/source hashes. Missing, unsigned, stale, torn, out-of-order or unresolved failed sessions refuse before publishing an assembly input. Extra custom request fields outside the installed `fields_for` schema require an explicit reviewed extension; they are not guessed. Do not rerun this producer after step 8 has already completed.

Actual dates stay in the inherited signatures. The October 9 experimental stop is unchanged. Full scope means D.4 core plus the extension only if actually admitted.
