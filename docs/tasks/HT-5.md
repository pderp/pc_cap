The separate recipe family `ht_stress_panel_v1` preserves the development banner and false/absent confirmation admission flags. It is a hash-pinned adaptation of R1-68b, leaving installed sources and existing drivers untouched. Both full and incremental integrity profiles work. Recipes bind the driver family, installed tree, selected primary, tokenizer, adapter, exact source rows and payloads. Each dataset gets shuffled and clustered schedules of exactly 100 distinct facts/subjects, with the identical first 20 and final 40 edits and the same middle-40 membership. The fixed probe set is exactly the first 20 source IDs, including failures to acquire them.

At edits 20/60/70/80/100 the driver records canonical and all source paraphrase exact-match outcomes and teacher-forced target-token NLL. Teacher forcing resets query state once per complete answer, retaining the prompt-conditioned selection during its later tokens. The fixed token population includes the terminating newline. Full state/parameter checks surround each probe phase, with restore and a failure record on mutation. Reference values from the original base are separately labelled and must stay identical across checkpoints.

Aggregation detail made explicit: recovery uses the pooled target-token mean of positive NLL differences from the same cell's edit-20 probe, across canonical prompts and all paraphrases, including terminal tokens. Thus longer answers and facts with more paraphrases contribute more token positions. Individual fact trajectories and canonical/paraphrase retention are also saved so that this weighting is visible; it is not an equal-fact macro presented as a token mean. Missing/nonfinite positions or changed identities fail the assay rather than shrinking its denominator.

Recovery requires mean positive degradation ≤.01 nat/token and canonical exact-answer count at least the edit-20 count, sustained at every subsequent measured checkpoint. Before all five measurements the answer is provisional. A qualifying edit-60 result has lag [0,0]; later recovery is interval-censored between the previous and current sampled lags. Failure through edit 100 is right-censored beyond 40 updates. No claim of measured recovery is made by these fixtures.

Checkpoint reports bind all raw probes and the edit history, snapshots and chain receipts. Resume restores a verified contiguous checkpoint prefix and rebuilds the edit-20 reference from its bound report. Failed phases retain cost and logs. An unclosed incremental journal or unknown supervisor spend refuses automatic continuation.

The supervisor holds the shared GPU lease, uses a single aggregate four-hour account across all six cells and retries, enforces MemAvailable ≥3 GiB, and stops by October 9's end in America/New_York. It charges child startup/model construction, edits, probes, retries and failures conservatively by wall time. A ≤.25 s watchdog polling interval bounds response to resource limits; process shutdown/scheduler latency can add a small overrun. The child is tied to the supervisor lifetime with Linux parent-death signalling. A host crash leaving an unclosed budget intent requires reconciliation; unknown spend is never treated as zero. The production CLI accepts execution only from this supervisor.
