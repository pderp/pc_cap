# AW-L3 — explicit read/write interface

**Status:** done for learner implementation and CPU acceptance tests. **Agent:** Codex. **Date:** 2026-09-20. **Inputs:** locked `RevisionCap`, acquisition/controller/store APIs, tiny JAX base, round-43 scope. **Outputs:** `aw/interface.py`, `aw/tests/test_interface.py`.

`InterfaceConfig` declares sorted nonempty `read_taps` and `write_sites`. Read selection is passed to both observation encoder and reader; unused projection tensors are physically absent, not merely fed zeros. When initialized from a full tree, retained tensors are unchanged. For the production dimensions, dropping bank 1 removes **393,472 parameters / 1,573,888 bytes**: 3,348,228 parameters become 2,954,756. Independent initialization with a reduced config is supported; the paired-seed study should initialize a shared full tree and prune it, as the preregistration states.

For restricted writes, a base proxy replaces inactive adjoints with exact zeros before the unchanged acquisition routine computes gradient norms or updates. Deltas start at zero and remain zero at those sites through every update and aggregate projection. Controller fallback and controller-plus-delta paths mask raw writes before the original bound. The corrected pass starts at the earliest active site, using that site's cached residual. The actual base, observations, acceptance/rollback, bank scales, aggregate A and step count are unchanged. The old deployment-only `single_site=True` configuration is rejected to prevent ambiguous semantics.

Storage rejects nonzero inactive deltas during insertion, replacement and snapshot import. Snapshots bind read/write semantics; invalid state is rejected before replacing the current store. All-site configurations retain the original semantic identity so the saved v5 checkpoint can be restored exactly. Changing interface/config identity clears selection and local JIT caches and refuses further prediction until a fresh learner is constructed and memories reacquired; importing valid state also clears caches. No global mutation of locked functions or another process's caches.

Memory accounting remains honest: reusable projection bytes fall with read taps, but the current stored delta arrays remain dense three-bank arrays with zero inactive slots. **Their full allocated bytes count toward the ceiling.** `interface_accounting()` reports physical bytes and active-coordinate bytes separately; removing write sites alone does not claim a threefold memory saving. Compact delta storage would be a separate implementation/validation task.
