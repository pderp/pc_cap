## Recipe and budget

The original base continues training on the same pinned uint16 OpenWebText shard, starting at token 0, using ordinary next-token cross-entropy. Adam uses the installed family's lr 1e-6, betas (0.9, 0.999), eps 1e-8 and zero weight decay, with fresh optimizer state, seed 1729, dropout off, sequence length 128 and batch size 1. It does not reproduce REG-02's PC relaxation or its sequence/batch schedule.

For a chunk starting at s with n valid inputs:

```text
input  = tokens[s : s+n]
target = tokens[s+1 : s+n+1]
loss   = mean CE over all n valid logits, including the last
next s = s+n
```

The final logit uses one lookahead source token. This differs from dropping the last logit of every chunk: all target indices remain consecutive, including boundaries. Causal context resets at each chunk. Padded bucket positions must be masked out in the future runtime.
