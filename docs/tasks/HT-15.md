# HT-15 — per-cell tails and realization spread

Capex, 2026-09-26. **Assigned CPU lane complete.** No model execution or GPU use.

`aw/tail_cells.py` reads a fixed snapshot of queue finish receipts, admits only
successful finishes with complete final endpoints, and checks recipe, final
receipt, checkpoint report, position inventory, and vector hashes. Multiple
references to the same attempt are deduplicated; competing completed attempts
for one coordinate require review. An empty receipt directory never falls back
to unreceipted files. This is descriptive analysis, not the owner's halt
reconciliation or an amendment to experimental admission.

Every cell has fractional positive-part ES99 from **imported
`aw.tail_figures.expected_shortfall`**, maximum with first location and tie count,
strict exceedance counts/fractions at .01/1/5 nats, signed mean, and half-positive-
mass count/fraction. Max locations use zero-based window and target-column
indices; target-token offsets start at 1. Zero positive mass has undefined
(`null`) concentration. All five vector fields must be finite, but these tables
use cap minus **own cap-off**; S1's total change from the original base is outside
this contrast.

The 262-cell snapshot has 18 observed condition/dataset groups: 17 complete
15-cell groups and partial S1_literal zsRE (5/2/0 cells by realization). Each
group lists the equal-weight cell mean, the three within-realization order
means, and the min–max of realization means only when all fifteen cells exist.
Incomplete groups remain visible. Ranges are not confidence intervals. Means of
cell maxima and concentration counts differ from the pooled statistics;
mean-cell and pooled ES99 are distinct estimands that can coincide.

Canonical outputs:

- `logs/additional_work/round47/HT-15-final/cell_tails.json`: all scalar values,
  coverage and input bindings, realization summaries, and exclusions (none in
  this snapshot).
- `cell_tails.csv`: one row per cell, including maximum locations.
- `tail_spread.md`: all seven requested summary metrics and realization ranges.
