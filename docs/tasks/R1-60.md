## Source audit

There are 9,218 source composition cases. Source preparation leaves 4,237 unavailable for the direct endpoint; this broader category must not be confused with the 19 conflicting source fact identities alone.

After the latest exposure supplement, 3,894 additional cases have excluded dependencies, and 1,087 have all dependencies among current candidates. Of those 1,087, 832 require one edited fact, 244 require two, and 11 require three. Multi-hop questions can depend on only one changed fact; report these strata separately.

These are graph ceilings, not expected attached-case counts or model successes. A final realization contains only a subset of candidate items. The registered three-realization population currently has a subject shortfall, so the audit intentionally reports final expected attached counts as unavailable. It does not present an infeasible draw as a valid expectation.
