# R1-58h — typed cost receipt v2

Status: producer/validator delivered; **unsigned receipt has pending evidence**.
Codex, round 28, 2026-09-17.

`scripts/r1_58h_cost_receipt.py` assembles 27 condition/dataset rows from the
declared ceiling table and completed development profiles, including their exact
recipe, payload, result, checkpoint, phase and journal bindings. It verifies the
batched integrity journals as well as ordinary phase receipts. It does not run a
model. The authoritative draft is `R1-cost-admission-receipt-v2.json` (the
`-review.json` file is a byte-identical build output); v1 is preserved as history.

`scripts/r1_58h_cost_contract.py` checks evidence completeness, exact 27-row
coverage, memory ceilings, current source hashes, full validation and the declared
budget/floor. The existing preflight calls this validator for cost schema v2
before approval checks, so it reports **pending evidence** even if someone flips
`lead_approved`. Synthetic complete receipts pass the actual preflight; missing,
duplicated, tampered and unmeasured rows fail.

## Bound policy and measurements

- Solo wall ceilings remain exactly `cell_ceilings_v1.json`; the stored factor is
  1.5 and two workers apply 1.15 once.
- Proposed shared budget: **750 process-hours = 2 × 375 h**. The expected combined
  core+extension process projection is **254.7825 h = 221.55 × 1.15**, approximately
  255 h; this is an estimate, not newly measured whole-matrix throughput.
- Measured JAX device peaks exist for **26/27 rows**; primary MQuAKE awaits its
  first profile. Device ceilings equal each selected measured peak × 1.5.
  The metric is JAX `peak_bytes_in_use`, not total `nvidia-smi` allocation.
- Host `MemAvailable` floor is **6144 MiB per launch**. The operator passes the
  signed receipt's floor into the existing queue API, including the first worker.
  This is a host launch guard, not a per-process host memory measurement.
- CounterFact supplies nine full near/revision profiles. Stable v0's combined
  phase time is 344.44 s, matching the approximate 345 s reference. Other
  conditions have their own measured values; one number is not substituted for all.
- Approximate 30 s startup/validation overhead is explicitly labelled an estimate.
  Retry-once, incomplete continuation, host-failure stop and charging failures are
  recorded and bound to plan v2 / concurrency policy v2.
