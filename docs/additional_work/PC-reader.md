# PC-trained reader — fixed comparison under DEC-077

2026-09-29, Capex. Defaults specified before supplemental training/evaluation. Local JAX; Capstan dispatches after the existing queue. This is post hoc work on exposed populations, separate from the primary R1 and acquisition-credit reports.

Train **three seeds (0, 1, 2) per rule**, BP and corrected ePC surrogate, using `aw/pc_reader_train.py`. Both arms start from the identical full parameter tree within seed and receive identical episode/token sequences. The frozen GPT-2 base and architecture stay fixed. The selected v5 source recipe is `results/R1/pilot/r1_50_stream_sel6_text_s2/summary.json`: first 1,000 items of each CounterFact v1 / zsRE v1 / MQuAKE v3 training pool, last 100 of each held out, 64-record mixed-domain episodes, eight queried records, eight outside records with paraphrase nulls, eight ordinary-text nulls from 512 training-range windows, batch two, 300 updates. Each seed uses the original text seed `seed + 7` and held-out episode seed `seed + 1000`. Training-range text stops at token 50,001,920; no evaluation item or outcome enters training/checkpoint choice.

Use AdamW, learning rate 0.001, weight decay 0.01, global gradient clipping at 1.0; ordinary answer CE, balanced retrieval loss and preservation KL, unit weights, zero code-norm penalty, κ=0 and no surprisal clipping. The bound is A=0.3 and the same calibrated three bank scales. **The evaluated artifact is the unweighted tensor average of checkpoints 150, 200, 250 and 300**, matching the selected v5 recipe; all four are required. Do not switch to the checkpoint with the best observed development or exposed-stream outcome. The original selected v5 artifact remains a separate historical reference.

The BP arm imports `FastTrainer`; PC imports **`revision_v1/epc_train.py`'s `EPCTrainer` and `EPCWriteGradients`**, with the corrected SD-24 energy, eight zero-initialized settling steps at error rate 0.1. Only the base-dependent answer/preservation gradient estimator changes. Retrieval and the reader/controller VJP remain exact autodiff; the base receives no updates. PC write-error magnitudes are used as that implementation specifies, without a new normalization or learning-rate compensation. Finite settling therefore changes gradient magnitudes as well as direction. PC's training answer diagnostic is settled CE, whereas BP's is feedforward CE; these are labelled separately. One common exact held-out retrieval diagnostic is logged but selects no checkpoint. The imported PC preservation head recomputes the teacher distribution in float32; the existing BP feature bank carries its declared float16 teacher approximation. Do not describe the two scalar diagnostic paths as numerically identical.

Evaluate each of the **six readers on both zsRE and CounterFact**, realization 0, order 100, first 300 edits: **12 evaluations**. Acquisition is **adjoint in every arm**, retaining the selected five-step delta rule, scales, null threshold, rare-token rule, early stopping, rollback and aggregate projection.
