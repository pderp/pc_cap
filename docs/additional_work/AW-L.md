# AW-L: trained read/write interface study — preregistration draft

2026-09-20 · Codex · **For lead review before GPU execution.** DEC-073 allocation A and `additional_work_plan_final.md`; local JAX only. CPU diagnostics do not select arms.

**Hypothesis.** Reading upper taps and writing only at the final site may preserve editing performance while reducing cost or ordinary-text harm; losing information/control may instead hurt. Lower layers are not assumed to be noise. This tests interfaces, not predictive-coding learning or matched-compute adapters.

**Design.** Read {1,2,3}/{2,3} × write {1,2,3}/{3}; taps follow blocks 4/8/12, with bank 3 before `ln_f`. Three paired training seeds **0,1,2** produce **six readers and 24 evaluations**: both write arms on zsRE and CounterFact for each reader. Train with the same v5 full-write objective, development pools, stream rules, checkpoint rule and budget. Initialize a full tree per seed, then prune excluded tap projections, preserving shared tensors. Write arms share reader/controller weights; separately optimized restricted-write training is not claimed. L4 must bind the exact training recipe and validate tap-shape plumbing before launch.

**Population.** First **300 edits**, sealed realization **0**, order **100**, per dataset; retain endpoint reservations and DEC-070 locality selection. Pair with corresponding block-1 cells. Label **post hoc evaluation on exposed confirmatory populations**: earlier outcomes informed project discussion, but no supplemental training, threshold, checkpoint, seed or arm selection uses these rows. Pilot on existing development data. Report failed seeds/edits. The selected original v5 artifact is a separate reference; all six supplemental readers are newly trained.

**Controls.** Reacquire memories for each write arm and rebuild keys for each reader. One aggregate **A = 0.3**, **five delta steps per answer prefix**, delta_lr = 0.1 in calibrated bank-scale units, tau = 0.1; preserve early stopping, rollback, rare-token and null rules. Mask gradients before normalization/update/projection, plus controller fallback and deployment. Deployment-only `single_site` is insufficient. Charge physically allocated dense delta zeros; fewer write sites grant no extra budget.

**Endpoints.** ES, RET-ES, RET-GS, LS, near-miss and revision at **100/300**, with planned denominators, missingness and failures; also unseen-question false fires, hard-null/firing and changed-distribution frequencies. At 300, full ordinary-text fidelity: **1,931 × 127 = 245,237 positions**, against own cap-off and original base. Report mean KL, signed ΔNLL, positive-harm maximum, ES99 including zeros, exceedances at **0.01/0.1/1 nat**, signed extrema and existing concentration/zero-mass statistics. Bind definitions/overflow/missing handling to final-plan/D.5 scoring; no independent-token uncertainty claim.

Show every seed/dataset/arm and paired read, write and interaction differences. **0.02 absolute descriptive tolerance** means RET-ES and RET-GS decline at most two percentage points against the matched all-read/all-write arm; display each difference. This is not inferential noninferiority or an automatic success label. Show fidelity and efficacy together. Three seeds on one population are not three independent subject realizations.

**Resources and gate.** Separately charge cache preparation, training, failed attempts, acquisition, observation full passes, corrected passes per fired query, decoding and fidelity scoring; report CPU time, peak host/device memory, parameters and actual stored bytes. L4 profiles development training/evaluation for each read set and both write masks, then projects six trainings/24 evaluations plus validation/retries. **48 GPU wall-hours is a ceiling.** Over-budget projections return to the lead under the final plan's cut order; never silently drop seeds. No supplemental GPU before primary release, no new fits after **October 6**, reporting October 7–8, hard experimental stop **October 9, 2026, 17:00 America/New_York**.
