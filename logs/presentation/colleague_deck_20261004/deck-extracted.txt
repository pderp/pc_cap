EXTREMES


A changed probability can reveal harm before the answer
changes

   Same text prefix, same observed next token


      ILLUSTRATIVE arithmetic                                ACTUAL main-study benchmark

      Base probability p₀ = 0.10                             45 / 45 learned-reader cells
      Cap probability pcap = 0.01                            exceed mean KL 0.001.
      Loss increase = log(10) ≈ 2.30 nats                    Their data-integrity checks pass.



   Observed-token loss and whole-distribution KL answer different questions.



Δ = log(p₀ / pcap) for the observed next token, at the same prefix. Positive Δ means worse prediction.

EXTREMES


A simple mixture gives a real per-token bound



        Frozen base                                                                 Corrected model

        37% base distribution                                                       63% cap distribution
        ρ = e⁻¹ ≈ 0.368                                                             1 − ρ ≈ 0.632




                                                  Probability mixture

                                                  q = ρp₀ + (1 − ρ)pcap
                                                  Every token retains a floor of ρp₀.


At a shared prefix, q ≥ ρp₀. Therefore log(p₀/q) ≤ −log ρ = 1 nat when ρ = e⁻¹.
