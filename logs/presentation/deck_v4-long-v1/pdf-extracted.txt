18 · What our error-inference experiment computes

Both acquisition arms start with the same target and use the same bounded memory-update rule.


   Adjoint credit                                                                                            Error-inference credit
   Differentiate the answer loss through the frozen                                                          Hold existing writes fixed. Start temporary site
   model. Use the negative, normalized gradient to                                                           errors at zero. Minimize a quadratic error penalty
   direct the correction.                                                                                    plus the answer loss, then normalize the inferred
                                                                                                             errors.




E(e) = ½ Σ ||e||² + answer loss with e
The default uses eight settling steps at rate 0.1. A one-step normalized update matches the adjoint
direction to numerical tolerance.

  This implementation uses automatic differentiation. Its PC component is iterative error
  inference, not biological locality.
Source: Corrected PC acquisition implementation and one-step controls; all results shown use the repaired energy.
